# 💰 Controle Financeiro Pessoal

Aplicação web para controle financeiro pessoal, desenvolvida com **HTML, CSS e JavaScript puro**, permitindo o registro de **receitas e despesas**, com cálculo automático de saldo e persistência de dados no navegador utilizando **LocalStorage**.

O projeto simula funcionalidades comuns de sistemas financeiros reais, com foco em **Front-end** e **experiência do usuário (UX)**.

---

## 🚀 Funcionalidades

- ➕ Adicionar receitas e despesas
- ❌ Remover lançamentos
- 🔎 Filtrar por:
  - Todos
  - Receitas
  - Despesas
- 💰 Cálculo automático de:
  - Saldo total
  - Total de receitas
  - Total de despesas
- 💾 Persistência de dados com LocalStorage
- 🎨 Interface moderna e intuitiva
- ⚡ Atualização dinâmica sem recarregar a página
